# Propiedades

Páginas de reserva de propiedades en alquiler temporario en Buenos Aires.
Se publican con GitHub Pages en `https://davidcortes377.github.io/propiedades/`.

| Carpeta | Propiedad | Dirección |
| --- | --- | --- |
| `casa-pena/` | Casa Peña | `…/propiedades/casa-pena/` |

- `index.html`: portada con el listado de propiedades.
- `fonts/`: tipografías compartidas por todas las páginas.
- Cada propiedad vive en su propia carpeta, con sus fotos, flyers y video.

Para agregar una propiedad nueva: crear su carpeta (se puede partir de una copia de
`casa-pena/`) y sumar una tarjeta en `index.html`.
